# PG AT ONE TOUCH

## Overview

PG AT ONE TOUCH is a PHP and MySQL based web application that helps students and working professionals find and book Paying Guest (PG) accommodations online.

## Features

* User Registration and Login
* PG Owner Registration and Login
* Add and Manage PG Listings
* Search PG Accommodation
* Online Booking System
* Booking Status Management
* Payment Module
* Admin Dashboard
* Owner Dashboard
* Contact and Inquiry Management

## Technology Stack

* PHP
* MySQL
* HTML5
* CSS3
* Bootstrap
* JavaScript

## Modules

### Admin Module

* Manage Users
* Manage Owners
* Manage PG Listings
* View Bookings
* Manage Reports

### Owner Module

* Add PG Details
* Update PG Information
* Manage Bookings

### User Module

* Search PG
* View PG Details
* Book PG Online
* Track Booking Status

## Database

Database file included:

```sql
pg_db.sql
```

## Installation

1. Download or Clone the Repository
2. Import `pg_db.sql` into MySQL
3. Place the project folder inside WAMP/XAMPP htdocs/www directory
4. Configure database connection
5. Start Apache and MySQL
6. Open the project in your browser
